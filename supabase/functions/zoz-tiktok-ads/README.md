# ZOZ Pro · TikTok Marketing API setup

This function is deployed as `zoz-tiktok-ads` in the production Supabase project. It supports owner-authenticated OAuth initiation, a one-time state callback, server-side token storage in Supabase Vault, advertiser/campaign reads, and read-only integrated advertiser reports.

## Required secrets (set in Supabase Vault; never commit or send values in chat)

- `zoz_tiktok_ads_app_id`: TikTok for Business developer app ID.
- `zoz_tiktok_ads_app_secret`: that developer app's secret.
- `zoz_tiktok_ads_authorization_url`: the exact **Advertiser authorization URL** generated by TikTok API for Business > My Apps > Basic Information. Do not replace it with a hand-built URL.

## Callback URL

Register this exact public callback URL in the TikTok developer app's advertiser redirect URLs:

`https://oxyzxbkwhafzaztraowc.supabase.co/functions/v1/zoz-tiktok-ads`

The callback is public by design because TikTok redirects the browser to it. It validates and consumes a high-entropy, short-lived, single-use state value stored as a SHA-256 hash and linked to the signed-in ZOZ owner. OAuth code exchange and tokens remain server-side.

## Actions

- `connect_start` (signed-in owner): returns the TikTok-generated authorization URL with a one-time state appended.
- `status` (signed-in owner): lists only that owner's connected advertisers.
- `sync` (signed-in owner, advertiser_id): reads advertiser details and campaign list.
- `report` (signed-in owner, advertiser_id, start_date, end_date): reads TikTok integrated advertiser report metrics.

All API operations are read-only. No campaign creation, budget change, ad activation, payment, or contract acceptance is exposed by this function. Those remain behind explicit owner approval and a separate reviewed workflow.

TikTok's advertiser access token is long-lived and does not expire under the current Marketing API docs. The deprecated refresh-token endpoint is intentionally not used.
