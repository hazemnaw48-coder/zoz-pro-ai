# ميثاق التشغيل الداخلي لعلامة ZOZ

**الإصدار:** 1.0  
**تاريخ الاعتماد التشغيلي:** 12 نوفمبر 2026  
**النطاق:** مشروع علامة تجارية يديره المالك، وليس كيانًا قانونيًا مسجلًا.

## 1. الهوية والوضع الحالي

- الاسم التجاري المستخدم: **ZOZ**.
- منصة التشغيل الداخلية: **ZOZ Pro**.
- البلد التشغيلي المستهدف: مصر.
- الوضع الحالي: علامة تجارية ومشروع مملوك ومدار من صاحبه، دون شركة مسجلة أو سجل تجاري مثبت.
- يحظر وصف ZOZ في العقود أو الحسابات الخارجية بأنه شركة مسجلة أو وكالة قانونية قبل استكمال التسجيل والتحقق من المستندات.
- هذا الميثاق سياسة تشغيل داخلية، وليس مستند تأسيس أو استشارة قانونية.

## 2. الغرض ونموذج العمل

إنشاء نشاط رقمي رشيق يديره فريق من وكلاء الذكاء الاصطناعي، مع تدخل المالك في القرارات القانونية والمالية والخارجية فقط.

### ترتيب الأولويات التجارية

1. **إنتاج الفيديوهات القصيرة للمشروعات الصغيرة:** المطاعم والمتاجر والمشروعات الصغيرة في مصر. المخرجات: موجز عميل، فكرة وسيناريو، خطة مشاهد، إنتاج/مونتاج ضمن النطاق المتفق عليه، مراجعة جودة، وتسليم الملف النهائي.
2. **استراتيجية المحتوى:** خطط المحتوى والسيناريوهات والتقويم والتقارير.
3. **إعداد المواد الإعلانية:** نصوص وموجزات إبداعية ومسودات حملات فقط، إلى حين وجود تفويض صحيح من صاحب حساب الإعلان.
4. **المنتجات الرقمية والنشر:** إعداد المنتجات والكتب ومتابعة تقارير KDP المتاحة، مع عدم افتراض إيراد غير مثبت.
5. **البرمجيات وZOZ Pro:** تطوير أدوات التشغيل كمنتج داخلي؛ لا يتم تسويقه كمنتج جاهز قبل موافقة المالك.

لا توجد أسعار نهائية أو وعود تسليم معتمدة في هذا الإصدار. أي سعر أو مدة يظل مسودة حتى مراجعة المالك واعتماده.

## 4. دورة العمل التجارية

1. تسجيل العميل المحتمل في النظام.
2. تأهيل الاحتياج وتحديد الجمهور والمخرجات المطلوبة.
3. إعداد نطاق العمل وعرض السعر كمسودة.
4. اعتماد المالك لأي عرض أو وعد خارجي.
5. استلام موجز العميل والمواد والتصاريح اللازمة.
6. إسناد الإنتاج إلى الوكيل المختص.
7. مراجعة مستقلة من العمليات والجودة.
8. اعتماد المالك للنسخة النهائية الموجهة للعميل.
9. التسليم وتسجيل التحصيل الفعلي، لا الإيراد المتوقع.
10. متابعة ما بعد التسليم وتوثيق النتائج.

## 5. صلاحيات الاستقلالية

### يسمح للوكلاء دون الرجوع للمالك

- البحث والتحليل الداخلي.
- كتابة الخطط والسيناريوهات والمسودات.
- توزيع المهام والمهام الداخلية العكوسة.
- مراجعة الجودة وتوثيق الأخطاء.
- قراءة البيانات من الحسابات المتصلة والمصرح بها.
- إنشاء تقارير وتنبيهات داخلية.

### يتطلب موافقة صريحة من المالك

- التواصل أو إرسال أي رسالة إلى عميل أو طرف خارجي.
- إرسال عرض سعر نهائي أو التزام بنطاق أو موعد.
- قبول عقد أو شروط قانونية.
- النشر العام لأي محتوى.
- تشغيل حملة إعلانية أو إرسالها للتسليم.
- أي شراء أو دفع أو إنفاق أو التزام ميزانية.
- تغيير وسيلة دفع أو صلاحيات أو ملكية حساب.
- منح طرف ثالث صلاحية وصول.
- حذف بيانات أو إجراء غير قابل للعكس.

**حد مالي للوكلاء دون موافقة:** صفر جنيه مصري.  
**القاعدة:** لا يُسمح باستدعاء خدمة مدفوعة أو ترقية أو شراء دون موافقة المالك.

## 6. الفصل بين العلامات والمسارات

- تشغيل القنوات العضوية لا يثبت وجود صلاحية لإدارة الإعلانات المدفوعة.
- حسابات فِكرة وما وراء الباب ومسار Hazem Ahmed تبقى منفصلة عن حسابات عملاء الإعلانات.
- BeyondMedia مسار وهوية تشغيلية للإعلانات المدفوعة، ولا يجوز وصفها كشركة مسجلة دون مستند.
- TikTok Marketing API لا يُعد متصلًا حتى ينجح التفويض الفعلي. لا يجوز استبداله ببيانات TikTok Display API العضوية عند إعداد تقارير الإعلانات.
- يبقى مسار نشر YouTube المعتمد عبر Production Center وبموافقة مالك مرتبطة بالفيديو المحدد دون أي تغيير بهذا الميثاق.

## 7. سياسة التكلفة

- الأولوية للمجاني.
- Gemini المجاني هو نموذج التشغيل الأساسي الحالي وفق إعدادات الإنتاج.
- لا توجد تبعية إلزامية إلى Make.
- الأدوات المدفوعة اختيارية وتحتاج حالة استخدام وتقدير تكلفة وموافقة صريحة.
- تسجل التكاليف الفعلية منفصلة عن التقديرات.

## 8. مؤشرات الأداء

| المؤشر | طريقة القياس |
|---|---|
| العملاء المحتملون المؤهلون | عدد السجلات التي استوفت شروط التأهيل |
| عروض الأسعار المعتمدة | العروض التي وافق عليها المالك وأُرسلت فعليًا |
| المشروعات المدفوعة | الطلبات ذات التحصيل المثبت |
| الإيراد المحصل | مبالغ دخلت فعليًا بالجنيه المصري |
| التسليم في الموعد | نسبة التسليمات في الموعد المتفق عليه |
| اجتياز الجودة | نسبة التسليمات التي اجتازت المراجعة |
| الإنفاق غير المعتمد | الهدف صفر |
| النشر المكرر | الهدف صفر |

لا توضع قيمة أساس أو هدف رقمي لمؤشر قبل جمع بيانات فعلية كافية.

## 9. خطة أول 30 يومًا

- **المرحلة الأولى:** اعتماد باقة خدمة الفيديو القصير، موجز العميل، نطاق العمل ومعايير القبول.
- **المرحلة الثانية:** تشغيل استقبال العملاء المحتملين وتأهيلهم دون مراسلة تلقائية.
- **المرحلة الثالثة:** تنفيذ نموذج تجريبي داخلي واحد وقياس زمن الإنتاج والتكلفة والجودة.
- **المرحلة الرابعة:** تجهيز دفتر مالي يفصل الإيراد المحصل عن المتوقع والمصروف الفعلي عن التقديري.
- **المرحلة الخامسة:** مقارنة خيارات التأسيس القانوني في مصر مع محاسب أو مختص، دون تسجيل أو دفع رسوم قبل قرار المالك.

## 10. الجاهزية القانونية

العناصر غير المكتملة حاليًا:
- اختيار الشكل القانوني المناسب.
- التسجيل التجاري والضريبي عند اللزوم.
- التحقق من متطلبات النشاط والاسم التجاري.
- دومين مملوك وبريد مهني على نطاقه.
- مراجعة شروط الخدمة والخصوصية والعقود بواسطة مختص.

لا يتم اختلاق عنوان شركة أو رقم سجل أو رقم ضريبي أو مستند ملكية. ولا يتم شراء دومين أو بدء اشتراك مدفوع أو دفع رسوم تسجيل دون موافقة المالك.

## 11. معيار اكتمال أي عمل

لا يسجل العمل مكتملًا إلا إذا:
- حُفظ المخرج في النظام أو الملف المقصود.
- ذُكرت الأدلة الفعلية والافتراضات بوضوح.
- اجتاز مراجعة الجودة المطلوبة.
- لم يتجاوز حدود الصلاحيات.
- لم يُدّع تنفيذ نشر أو دفع أو تواصل خارجي لم يحدث.
