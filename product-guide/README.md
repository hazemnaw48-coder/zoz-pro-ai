# دليل ZOZ Pro — منتج فِكرة الأول

## الحالة
- صفحة التسجيل: جاهزة في فرع التطوير.
- الدليل العربي: موجود كصفحة HTML قابلة للطباعة والحفظ PDF من المتصفح.
- استقبال الاهتمام: Edge Function `zoz-product-leads` v2 منشورة في Supabase.
- جدول الاهتمام: RLS مفعّل، ولا توجد سياسات أو منح للأدوار العامة؛ الإدخال يمر عبر الوظيفة الخادمية.
- النشر العام: **غير معتمد وغير منفذ**؛ ينتظر مراجعة المالك ودمج PR #46.

## ما لا يفعله المنتج حالياً
- لا يبيع أو يجمع مدفوعات.
- لا يرسل رسائل بريد آلية.
- لا يدعي أن الطلب أو الإيراد مثبت.
- لا ينفذ نشر محتوى أو تواصلاً مع المسجلين تلقائياً.

## اختبار ما قبل الإطلاق
1. شغّل `python3 scripts/validate_product_guide.py`.
2. اختبر روابط الصفحات ومراسي الأقسام.
3. اختبر تسجيل بيانات اصطناعية مع موافقة صريحة.
4. تحقق من منع التسجيل دون موافقة ومن رفض المدخلات غير الصحيحة.
5. تحقق من عدم ظهور أي صف في REST API للأدوار العامة.
6. احذف سجل الاختبار وتأكد من عدم بقائه.
7. أضف تحديد معدل/حماية إساءة استخدام قبل نشر رابط التسجيل علناً.
8. راجع إشعار البيانات ونص الموافقة، ثم اطلب موافقة المالك على الدمج والنشر.

## الروابط
- `index.html`: صفحة الاهتمام.
- `guide.html`: الدليل العملي.
- `data-notice.html`: إشعار البيانات والحذف.
- `privacy.html`: مسار قديم يحوّل إلى إشعار البيانات الحالي.
