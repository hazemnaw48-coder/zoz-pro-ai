دخول المالك

استخدم حساب مالك ZOZ Pro المؤكد. لا تضع مفاتيح API هنا.

1 · تحليل القناة

يقرأ الوكيل حالة القناة والتحليلات والتقويم والمسودات وملفات الفيديو، ثم يعرض تشخيصًا وخطوات عملية. التحليل لا ينشر ولا يغيّر إعدادات الفيديو.



2 · إنشاء مسودة محتوى
يختار المالك موضوعًا أو يكتب موضوعًا مقترحًا؛ يحفظ النظام السيناريو في مركز الإنتاج للمراجعة. لا يتم إنشاء فيديو أو رفعه أو نشره تلقائيًا.


3 · سجل التشغيل
تُحفظ نتائج التحليل وإنشاء المسودات في سجل الأتمتة عند نجاح الكتابة. الموافقة على النشر تبقى للمالك.




المشروع: Supabase الإنتاج · لا نشر تلقائي · لا تغيير في صلاحيات القنوات.
