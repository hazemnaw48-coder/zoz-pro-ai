# ZOZ Flow Bridge — Android companion (prototype)

This is the first installable foundation only. It opens Google Flow, copies a scene prompt to the clipboard, and imports selected video files through Android's document picker.

Not implemented yet:
- ZOZ Pro owner sign-in or agent job sync
- Google Flow UI automation
- automatic clip download
- on-device video assembly
- upload to ZOZ Pro intake
- YouTube private upload or publication

Do not use this prototype as a finished production pipeline. It contains no Google credentials, Supabase service key, or intake token.
