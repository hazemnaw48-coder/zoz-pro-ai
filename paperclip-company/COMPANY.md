# ZOZ Pro

ZOZ Pro شركة رقمية مستقلة. Paperclip هو مكتب الإدارة وتنسيق الأهداف والمهام والموافقات، بينما تبقى Supabase قاعدة بيانات وتشغيل ZOZ Pro الحالية هي مصدر بيانات القنوات والمنتجات والملفات. لا يستبدل Paperclip أي خدمة إنتاج قائمة.

## طريقة العمل

النمط الإداري Hub-and-spoke: المدير التنفيذي يستقبل الأهداف ويجزئها إلى مهام ويوزعها على تسعة اختصاصيين، ثم يراجع النتائج ويجمعها في توصية واحدة. لا تُنشأ مهام متكررة أو تشغيلات دورية بلا حاجة. الإيقاظ يكون عند وجود مهمة أو طلب صريح، وليس عبر نبضات زمنية متكررة.

## سياسة الأمان والتكلفة

- العمل داخل المسودات والتحليل والتخطيط والبحث المسموح والاختبارات غير المدمرة يمكن تنفيذه باستقلالية.
- النشر العام أو تعديل حسابات القنوات أو الكتب، إرسال رسائل للعملاء، شراء الخدمات، الإنفاق، حذف البيانات أو أي تغيير خارجي حساس يتطلب موافقة المالك قبل التنفيذ.
- لا تستخدم خدمات مدفوعة أو تتجاوز الحصص المجانية. لا تربط حسابات النماذج بالفوترة المدفوعة. عند نفاد الحصة، سجّل سبب التوقف ولا تنتقل تلقائياً إلى مسار مدفوع.
- لا تضع مفاتيح أو كلمات مرور أو رموز OAuth أو روابط اتصال سرية في GitHub أو ملفات الشركة أو تعليقات المهام. تُحفظ المفاتيح في مخزن أسرار Paperclip المحلي المشفر، منفصلاً عن مستودع GitHub.
- لا تدّع أن أداة أو قناة متصلة لمجرد تسجيلها في الكتالوج. لا تعتبر أي مهمة مكتملة حتى يوجد مخرج فعلي وسجل تشغيل يؤكد ذلك.
