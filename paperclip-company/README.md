# ZOZ Pro — Paperclip Company Package

حزمة استيراد مكتب الشركة إلى Paperclip، مبنية على هيكل الأقسام العشرة الذي اعتمده المالك.

## الهيكل

| الوكيل | المهمة |
|---|---|
| CEO | الإدارة التنفيذية وتوزيع الأولويات |
| Research Lead | البحث والتحقق |
| Content Producer | إنتاج المحتوى |
| Digital Product Manager | المنتجات الرقمية |
| Publishing Manager | دار النشر وKDP |
| Services Manager | الخدمات الرقمية |
| Software Engineer | التطبيقات والتكاملات |
| Sales & Marketing | التسويق والنمو |
| Finance Controller | المالية والامتثال |
| Operations & QA | العمليات والجودة |

كل الوكلاء يتبعون المدير التنفيذي مباشرة في المرحلة الأولى. هذا تصميم Hub-and-spoke لتجنب التعقيد الإداري المبكر.

## طريقة التشغيل المجانية

- استخدم نسخة Paperclip مفتوحة المصدر ومستضافة محلياً على هاتف Android عبر Termux + Debian PRoot. هذا مسار تجريبي مجتمعي وليس هدف نشر Android مدعوماً رسمياً من Paperclip.
- استخدم قاعدة Paperclip المدمجة المحلية وتخزينه المحلي. لا توصل Paperclip بقاعدة إنتاج ZOZ أو Preview ولا تنشئ مشروع Supabase إضافياً.
- استخدم Gemini CLI محلياً مع Gemini free-tier / Google sign-in. لا تربط خطة مدفوعة ولا تفعّل فوترة. عند نفاد الحصة، أوقف التشغيل حتى تتجدد الحصة.
- تُضاف مفاتيح Gemini (إن وجدت) إلى مخزن Paperclip المحلي المشفر بواسطة سكربت الإعداد الآمن. قيم المفاتيح لا تدخل هذه الحزمة.
- Qwen ليس مفعلاً في الحزمة الأولى. يُضاف لاحقاً عبر OpenCode بعد اختبار API والحصة المجانية، دون المساس بتشغيل Gemini الأساسي.

## استيراد الشركة

من داخل Termux بعد تثبيت وتشغيل Paperclip:

```bash
bash ~/zoz-pro-ai/paperclip-android/import-company-termux.sh
```

يقوم السكربت أولاً بعرض المعاينة الجافة (dry-run) ثم يطلب كلمة تأكيد واضحة قبل إنشاء الشركة. لا يدمج هذه الحزمة في شركة أخرى ولا يستبدل سجلات قائمة.

## إعداد مفاتيح Gemini الاختياري

```bash
bash ~/zoz-pro-ai/paperclip-android/configure-gemini-keys-termux.sh
```

يقبل السكربت مفاتيح الحسابات الثلاثة بإدخال مخفي، ويحفظها في مخزن أسرار Paperclip المحلي المشفر ويربط كل مجموعة بالوكيل المناسب. لا يطبع القيم ولا يرسلها إلى GitHub أو Supabase أو هذه المحادثة. اترك الحقل فارغاً لتخطي الحساب. لا تُستبدل أي قيمة موجودة تلقائياً.

## التشغيل والتحقق

```bash
bash ~/zoz-pro-ai/paperclip-android/start-termux.sh
bash ~/zoz-pro-ai/paperclip-android/status-termux.sh
```

افتح على الهاتف فقط: http://127.0.0.1:3100

أوقف الخدمة:

```bash
bash ~/zoz-pro-ai/paperclip-android/stop-termux.sh
```

كل نبضات الوكلاء الزمنية تبقى متوقفة افتراضياً. شغّل أول وكيل يدوياً بعد التأكد من تثبيت Gemini CLI وإعداد مصادقة أو مفتاح مجاني. لا تفعل الوكلاء العشرة دفعة واحدة.

## حدود مهمة

- Paperclip سيعمل فقط أثناء عمل خادم Termux على الهاتف. إغلاق Termux أو إيقاف Android قد يوقفه؛ لا يوجد ضمان تشغيل سحابي 24/7.
- لا تفتح المنفذ 3100 على الإنترنت ولا تستخدم وضع public أو local_trusted عبر شبكة عامة. الوضع المحلي الآمن يربط الخدمة بعنوان loopback.
- قاعدة Paperclip المدمجة منفصلة تماماً عن Supabase. لا تتغير بيانات إنتاج ZOZ Pro أو Preview عند التثبيت أو الاستيراد.
- وجود وكيل في الهيكل لا يعني أنه نجح في تنفيذ مهمة. يجب تشغيل اختبار واحد ورؤية نتيجة فعلية في Paperclip.
- لا توجد مزامنة تلقائية بعد بين مهام Supabase القديمة وPaperclip. نضيف مزامنة ثنائية الاتجاه فقط بعد اختبار الربط واعتماد عقد API.
