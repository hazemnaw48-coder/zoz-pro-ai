إنشاء مهمة محتوى

Gemini يُستخدم أولًا لكتابة النص والمشاهد. إذا تعذّر، يستخدم النظام مولّدًا محليًا احتياطيًا. لا يبدأ النشر العام تلقائيًا.

المهام المحفوظة

اختر مهمة لتوليد النص، ثم حاول إنشاء الفيديو. لا يتم خصم رصيد فيديو إلا عند طلب الإنشاء.

سجل النشر

YouTube

تفويض مباشر إلى Supabase. يحتاج تطبيق Google OAuth ومفاتيحه في أسرار Edge Functions، ثم موافقة القناة مرة واحدة.

TikTok

يتطلب TikTok Developer App وموافقة الصلاحيات video.upload وvideo.publish. قد يقيّد TikTok النشر العام حتى اعتماد التطبيق.

القنوات المتصلة

رفع مهمة إلى قناة

يتاح بعد وجود فيديو جاهز وتفويض مباشر. يبدأ YouTube بخصوصية خاصة، وTikTok بوضع SELF_ONLY حتى المراجعة.

Gemini

اختبار API من داخل Supabase باستخدام GEMINI_API_KEY دون كشف المفتاح.

Claude

ربط مباشر إلى Anthropic API. لا يعتمد على سيناريو Make. يحتاج ANTHROPIC_API_KEY في أسرار Supabase.

حالة جميع الأدوات

سياسة الاعتماد

  • Supabase هو مصدر البيانات ومركز التحكم.
  • Make وRunway احتياطيان اختياريان فقط.
  • لا توجد أسرار API في المتصفح أو GitHub.
  • GitHub Pages يستضيف الواجهة الثابتة دون حد بناء يومي خاص بـFloot.
  • النشر العام يظل معطّلًا افتراضيًا حتى اعتماد كل منصة وتأكيدك.

تفاصيل الحالة الخام

لا تحتوي الاستجابة على رموز OAuth أو مفاتيح API.
